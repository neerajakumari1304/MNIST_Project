# MNIST_Project
The MNIST (Modified National Institute of Standards and Technology) dataset is a widely recognized and fundamental dataset in the field of machine learning and computer vision. 
This project demonstrates how to build and evaluate multiple machine learning models on the MNIST dataset (handwritten digits). It is structured using an object-oriented approach for clarity, reusability, and scalability.
- Implements and compares **multiple ML algorithms**:
- KNN

- Naive Bayes

- Logistic Regression

- Decision Tree

- Random Forest

- AdaBoost

- Gradient Boosting

- XGBoost

SVM (RBF Kernel)
- Provides a unified class `MNISTModels` to:
  - Load and preprocess data
  - Train all models
  - Evaluate performance with accuracy scores
✔ Compute:
- Accuracy
- Confusion Matrix
- Classification Report
- ROC-AUC score for each model
